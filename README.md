# dotfiles

Personal configuration files for macOS and Linux.

## Contents

- `zsh/` – Zsh config, aliases, and plugins
- `git/` – Git global config and ignore
- `vim/` – Vim settings and keybindings
- `scripts/` – Utility helpers

## Setup

Clone and run `./install.sh` to symlink dotfiles into `$HOME`.

See individual directories for details.
